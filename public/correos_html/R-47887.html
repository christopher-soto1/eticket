Dear Customer,

We’re pleased to announce that FortiGate Cloud version 25.4 is scheduled for release on November 5, 2025. This update introduces several new features and important fixes designed to enhance performance, usability, and security.

Release Highlights

  • FortiConverter: Now supports automatic vendor detection.
  • Portal Enhancements: Improved responsiveness and scalability for organizations with over 20,000 devices.
  • Cloud Access Management: Cloud access mode can now be configured at the organization level.
  • Event Handling: Added support for event handler creation, customization, and monitoring.

Key Bug Fixes

  • Resolved an issue where FortiGate HA pair details were not displayed correctly.
  • Fixed a firmware upgrade issue affecting FortiGate 70G devices.
  • Addressed a problem where Sandbox setting changes were not saved in some cases.
  • Fixed an issue where the FortiView Traffic Log negation filter for the Service column did not function as expected.
  • Resolved an issue where changes to event handler email settings were not applied in certain situations.

Thank you for choosing FortiGate Cloud. We appreciate your continued trust and partnership.
