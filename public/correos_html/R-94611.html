Frequently Asked Questions (Q&A)

Q: Where to find more information on the upgrade requirements and versions?
A: Please see https://docs.fortinet.com/document/fortigate-cloud/25.4.a/administration-guide/925021/requirements on the requirements.

Q: What if I have a device not managed by FortiGate Cloud or not using FortiGate Cloud?
A: This is applicable to only devices managed by FortiGate Cloud and not having FortiGate Cloud subscription. If your device is deployed to FortiGate Cloud and not using the service, you can deprovision the device from the cloud from fortigate.forticloud.com

Q. What if I don't want to update the firmware?
A: If not upgraded, access to the device from cloud and logging will be restricted. However, the device will continue to work standalone without cloud management. It is recommended to purchase FortiGate Cloud subscription to continue accessing and managing device from Cloud or if cloud management is no longer needed, deprovision the device.

Q. What subscription would I need to buy?
A. FortiGate Cloud subscription can be purchased via standard SKU, through an authorized partner, or via the FortiMarketplace (Asset Management) if you have purchased FortiPoints. Please see https://docs.fortinet.com/document/fortigate-cloud/25.4.a/administration-guide/568218/subscription-types

Q. Is there a way to automate updates?
A. For devices with subscription automatic upgrades can be setup via cloud using firmware profiles (https://docs.fortinet.com/document/fortigate-cloud/25.4.a/administration-guide/116095/firmware-management). For devices without FortiGate Cloud subscription, automatic upgrades can be setup via FortiOS (https://docs.fortinet.com/document/fortigate/latest/administration-guide/369092/enabling-automatic-firmware-upgrades).
